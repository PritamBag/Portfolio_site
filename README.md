## About

This repository contains the personal portfolio website of Pritam Bag, a Software Development Engineer from Kolkata, West Bengal, India.

Pritam came into software through mathematics. He completed a B.Sc in Mathematics from Barasat College, followed by an MCA from Techno India Hooghly, and carried that habit of structure-first thinking into engineering work that values clarity, maintainability, and systems that keep working after the first release.

## Professional Direction

His work lives closest to backend and operational software: Laravel applications, reusable packages, WordPress and WooCommerce customization, Dolibarr ERP work, integrations, deployment-sensitive systems, and business software that has to survive real use on an ordinary Monday morning.

He has worked across Rxefy Tech Pvt Ltd, Wrappid, and Iquester Solutions LLP, contributing to framework work, application architecture, integrations, multi-tenant systems, ERP customization, and custom platforms for business operations.

## What This Portfolio Holds

This portfolio brings together the work that best represents Pritam Bag:

- Laravel backend systems and reusable package work
- WordPress, Dokan, and WooCommerce customization
- Dolibarr templates, external modules, fixes, upgrades, and deployment support
- Integrations involving Zoho Books, WhatsApp, Messenger, and operational workflows
- Selected projects such as Knorai, TrackShoot, Queriverse, multi-vendor commerce work, automobile dealer backend systems, and Laravel package development
- Certifications, resume details, and writing based on real project experience
